# Optional benchmarks

These benchmark families are retained for possible future investigations, but
they do not feed the current target plot list and are excluded from
`data/suites/all.yaml`:

- `confidence_correctness`
- `conversation_memory`
- `inbox_routing`
- `india_focused_tasks`
- `negative_instructions`
- `tables_to_decisions`

Run them explicitly through `data/suites/optional.yaml`. Their source data and
generated items remain in the repository so moving them out of the headline
scope is reversible.
